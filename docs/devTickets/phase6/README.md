# Phase 6 — Quizzing MVP

**Objective.** Deliver the active-recall loop from a saved, content-informed quiz through feedback, repeat, and export.

**Deliverable.** Quiz generation and library, a player that hides marking criteria until submit, deterministic multiple-choice marking, AI-assisted short-answer feedback, attempt history, and basic export.

**Depends on.** Phase 5 context assembly and the AI boundary, Phase 4 content, and Phase 3 usage limits.
