# Phase 1 — Foundations and architecture

**Objective.** Run the React client, both Express APIs, and MongoDB locally, and prove they connect.

**Deliverable.** The frontend shows connectivity for a check that travels React → `server-webApp` → `server-data` → MongoDB.

**Depends on.** Local Node, MongoDB, and environment configuration. No earlier product phase.
